プライバシーポリシー

Hana Mediabox（ウェブ版・Android アプリ版）／ 最終更新日: 2026年7月30日

Hana Mediabox（以下「本サービス」）は、招待された少人数の利用者が音声・動画・画像・書籍などの メディアを共有し、チャットで会話するための個人向けサービスです。本ポリシーは、本サービスが取得する 情報とその取り扱いについて説明します。

1. 取得する情報

種類 内容
アカウント情報 共有パスワードによるログイン時の識別子（ゲストキー）。Google アカウントでログインした場合は、メールアドレス・表示名・プロフィール画像。
投稿・アップロード内容 アップロードしたメディアファイル（音声・動画・画像・書籍）とそのタイトルなどのメタデータ、 チャットで送信したメッセージ本文。
端末・接続情報 User-Agent、端末種別・端末名、ブラウザ、OS、言語設定、タイムゾーン、画面サイズ、 IP アドレス、IP アドレスから推定される都市・地域・国・おおよその緯度経度・接続プロバイダ名。
利用状況 アクセスした画面のパス、参照元 URL、アクセス日時、再生した項目。
プッシュ通知トークン Android アプリ版で通知を許可した場合、Firebase Cloud Messaging の端末トークン。トークンは識別用にハッシュ化した値とあわせて保存します。

位置情報は GPS では取得しません。IP アドレスからの推定のみで、精度は都市レベルです。

2. 利用目的

  • メディアの保存・配信およびチャット機能の提供
  • 新着メッセージのプッシュ通知の配信
  • 不正アクセスや不審な利用の確認（管理者向けアクセスログ）
  • 不具合の調査および機能改善

3. 情報の保管と第三者サービス

データは以下のサービス上に保管・処理されます。

  • Google Firebase（Firestore / Storage / Authentication / Cloud Functions / Cloud Messaging / Analytics） — Firebase プライバシーとセキュリティ
  • IP 位置情報 API（ipwho.is / geojs.io / ipapi.co） — アクセス元の国・地域の推定のためにリクエスト時の IP アドレスが送信されます。

上記以外の第三者に個人情報を販売・提供することはありません。法令に基づく開示請求があった場合を除きます。

4. 広告・トラッキング

本サービスは広告を表示せず、広告目的のトラッキングや第三者への行動データの提供も行いません。

5. 保存期間と削除

アップロードされたメディアとチャットメッセージは、利用者または管理者が削除するまで保存されます。 アクセスログは運用上必要な期間のみ保持します。プッシュ通知トークンは、無効化を検知した時点で 自動的に削除されます。

6. データ削除の請求

アカウントに関連するデータの削除をご希望の場合は、下記の連絡先までご連絡ください。 本人確認のうえ、原則30日以内に削除します。アプリをアンインストールすると、 その端末へのプッシュ通知は停止します。

7. 通知の許可について

プッシュ通知は端末の設定でいつでも無効にできます。Android の 設定 → アプリ → Hana Mediabox → 通知 から変更できます。

8. 子どもの利用について

本サービスは招待制の個人向けサービスであり、13歳未満の子どもを対象としていません。 13歳未満の子どもから意図的に個人情報を収集することはありません。

9. セキュリティ

通信は HTTPS で暗号化されます。データへのアクセスは Firebase セキュリティルールによって制限されています。ただし、インターネット上の通信および保管において 絶対的な安全性を保証することはできません。

10. 本ポリシーの変更

本ポリシーは必要に応じて変更されることがあります。重要な変更がある場合は、本ページの 最終更新日を更新して告知します。

11. お問い合わせ

本ポリシーに関するお問い合わせは、本サービス内のチャット、または管理者の連絡先までお願いします。
